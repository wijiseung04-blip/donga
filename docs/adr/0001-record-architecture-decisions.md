# ADR-0001: 기술 결정을 ADR로 기록한다

- 상태: 승인됨
- 날짜: 2026-11-02
- 결정자: @wijiseung04-blip

## 배경 (Context)
브랜치 보호 방식처럼 여러 선택지를 비교해 내린 결정이 PR 코멘트와 대화에 흩어져, 나중에 이유를 다시 찾기 어렵다.

## 검토한 선택지 (Options)
1. PR 본문에만 기록: 추가 작업이 없지만 검색이 어렵고 PR 단위로 흩어진다.
2. 위키에 기록: 편집은 쉽지만 코드와 별도로 관리되어 리뷰를 거치지 않는다.
3. 저장소 `docs/adr/`에 Markdown으로 기록: PR 리뷰를 거치고 코드와 함께 버전 관리된다.

## 결정 (Decision)
선택지 3. 되돌리기 어렵거나 여러 선택지를 비교한 결정은 `docs/adr/NNNN-제목.md`로 기록한다.

## 결과 (Consequences)
- 결정의 이유를 PR 리뷰로 검토하고 이력으로 남길 수 있다.
- 결정마다 문서를 쓰는 비용이 든다. 사소한 결정은 기록하지 않는다.
