# StudyTimer

Python 기반 터미널 학습 시간 관리 프로그램

## 1. 프로젝트명

StudyTimer CLI

## 2. 문제정의

공부 시간을 정확하게 측정하고 기록하기 어렵고,
누적된 학습 시간을 확인하는 과정이 번거롭다.
StudyTimer는 터미널에서 공부 시간을 측정하고
기록하여 학습 시간을 효율적으로 관리할 수 있도록 한다.

## 3. 핵심 기능

### 1. 공부 시간 측정
- 공부 시작
- 일시정지
- 재개
- 종료

### 2. 공부 기록 관리
- 날짜별 기록
- 과목별 기록
- 기록 조회
- 기록 수정 및 삭제

### 3. 학습 통계 및 목표 관리
- 일별/주별/월별 통계
- 목표 공부 시간 설정
- 목표 달성률 확인

## 4. 기술 스택

- Python
- SQLite(파일 기반 관계형 데이터베이스)
- pytest
- Git
- GitHub
- GitHub Actions
